# 📊 Fertility Clinic Analytics

> Análise de dados e indicadores para apoio à tomada de decisão em operações de uma clínica de reprodução humana.

## 🎯 Objetivo do projeto

Este projeto tem como objetivo organizar, analisar e transformar dados operacionais em informações que possam apoiar o acompanhamento de indicadores e a tomada de decisão.

A proposta é utilizar dados para identificar padrões, acompanhar resultados e facilitar a visualização das principais informações do negócio.

## 📌 Contexto

O projeto foi desenvolvido como um estudo prático de análise de dados aplicado ao contexto de uma clínica de reprodução humana.

A abordagem combina análise de dados, indicadores e visualização de informações para transformar dados operacionais em insights.

## 🛠️ Tecnologias e ferramentas

- Microsoft Excel
- Power BI
- Análise de dados
- Indicadores e KPIs
- Visualização de dados
- Gestão e melhoria de processos

## 📈 Indicadores

Os indicadores analisados neste projeto serão apresentados a partir dos dados disponíveis, buscando facilitar:

- acompanhamento de resultados;
- identificação de padrões;
- análise de desempenho;
- visualização de informações;
- apoio à tomada de decisão.

## 🔎 Análise

A análise busca responder perguntas relacionadas ao desempenho operacional e aos principais indicadores do negócio.

Os resultados serão apresentados por meio de tabelas, gráficos e dashboards.
